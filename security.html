Audit trail

A ledger nobody can quietly edit

Every sensitive action — sign-ins, membership changes, budget edits, SSO configuration, model and storage changes — is written to an append-only audit log.

  • check_circle Append-only enforcement at the core level, no app overrides
  • check_circle Even a compromised admin credential can't rewrite or delete history
  • check_circle Covers sign-ins, role & membership changes, budget edits, and SSO / model / storage configuration
