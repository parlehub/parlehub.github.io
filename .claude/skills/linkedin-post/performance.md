# LinkedIn post performance log

Read this before drafting (see SKILL.md, Step 1). One row per published post. Fill the
metrics in about 7 days after posting, from LinkedIn's post analytics. Do not put customer
names, commenter names, or private figures here; this repo is public.

## Fields

- **Posted:** date published (YYYY-MM-DD).
- **Source:** the `_posts/` file the post came from.
- **Angle:** core idea, section mini-lesson, or concrete scene.
- **Hook type:** number or scene, reversal, named pattern, or blunt question.
- **Hook:** the first line, verbatim.
- **Chars:** character count of the published post.
- **Media:** none, one screenshot, several images, or carousel.
- **Link:** in the first comment, or in the body.
- **Impressions / Reactions / Comments / Reposts / Link clicks:** at about 7 days.
- **Notes:** what the comments asked, anything that surprised you, what to repeat or avoid.
